# MyToken 首次运行说明

## 安装

1. 打开下载的 MyToken 安装镜像（例如 `MyToken-1.2.0-arm64.dmg`）。
2. 将“MyToken”拖入“应用程序”文件夹。
3. 在“应用程序”中打开“MyToken”。

## 首次允许运行

MyToken 目前采用未签名方式交付。macOS 15 及更高版本对从网络下载的未签名应用会更严格，可能出现“无法打开”或应用没有任何界面。这通常是 Gatekeeper 拦截，不是应用运行时崩溃。遇到提示后：

1. 打开“系统设置 → 隐私与安全性”。
2. 在安全性区域找到 MyToken 的拦截提示，选择“仍要打开”。
3. 在随后出现的确认窗口中再次确认打开。

完成一次确认后，后续可正常从“应用程序”启动。

## 更新与发布

应用会在启动时检查 `dick86114/MyToken` 的最新 GitHub Release。发现新版本后，菜单栏弹窗和“设置 → 通知与系统 → 软件更新”会显示提示，可直接下载并安装；如果系统拒绝覆盖“应用程序”中的旧版本，请按提示手动打开 DMG 安装。

仓库的 CI 会在每次提交和 Pull Request 时运行测试并生成 DMG 构建产物。需要发布版本时，在 GitHub Actions 手动运行“发布版本”工作流，填写三段式版本号（例如 `1.2.0`），工作流会创建对应 Release 并上传 DMG。

## 问题反馈

如果遇到检查更新失败、下载失败或更新后未自动重启，可以在菜单栏图标上右键点击“提交问题”，或在“设置 → 通知与系统 → 软件更新”中点击“提交问题”。应用会打开预填充的 GitHub Issue 页面，并附带版本、系统信息和最近的脱敏诊断日志；最终提交前请自行确认 Issue 正文。

## 供应商凭证

首次启动后进入“设置 → 账户”，点击“添加”，先选择供应商，再输入对应的 API Key 或 Access Key/SecretAccessKey。验证成功后才会保存凭证。

同一供应商下的多个凭证会独立显示，不会合并计算。设置中可以为 1～4 个凭证打开“菜单栏指标”，菜单栏会以竖向单元显示这些凭证。

具有明确配额上限的供应商显示用量进度。DeepSeek 当前显示余额和余额健康状态，不代表已使用百分比。

## Routin 每日签到

点击菜单栏弹窗顶部的签到图标，或前往“设置 → 通知与系统 → Routin 签到”后点击“立即签到”。首次使用时会打开 Routin 官方登录页；请在页面中自行完成密码、验证码或第三方授权登录。登录成功后，应用会回到官方签到页并继续本次抽奖。

MyToken 不保存 Routin 的账号密码、验证码、Token 或 Cookie。登录会话由应用内网页的系统网站数据管理；可以在同一设置区域选择“重新登录”或“退出登录”。退出登录只清除 Routin 网页站点数据，不会删除凭证或用量记录。若显示“无法确认签到结果”，请直接查看该官方签到页面确认当天状态。

## Codex 当前分组

菜单栏弹窗中，每个 Key 的分组倍率右侧都有“获取 Codex 当前分组”按钮。确认后，MyToken 会使用该 Key 发送一次真实但低额度的 Codex 探测请求，并到 Routin 官方请求日志页面查找带有唯一标识的对应记录；因此不会根据其他请求日志猜测分组。首次使用如未登录，会打开官方登录页，完成登录后自动继续本次检测。

检测成功后，与该 Key 关联的 Routin 账号和当前分组会显示在“设置 → Key 管理”中；菜单栏中同名分组及其当前接口返回的倍率会显示为绿色。应用只保存账号邮箱规范化后的摘要、账号显示名、分组名和检测时间，不保存邮箱原文、Cookie、网页登录令牌、完整 Key 或探测标识。修改 Key 密文、删除 Key 或在设置中解除关联都会清除该检测记录。

## 本地凭证与卸载

你添加的凭证配置和秘密材料保存在当前 macOS 用户的应用本地存储中，不会随应用包分发。卸载 MyToken 不会自动删除本地数据；如需彻底移除，请先在应用内删除全部凭证，再卸载应用。
